# Улучшения навигации — Инновационная система

## 🎯 Что сделано

### 1. **Breadcrumbs (Хлебные крошки)**
- Автоматический путь навигации на всех страницах
- Кликабельные элементы для быстрого возврата
- Адаптивная версия для мобильных устройств
- Файл: `frontend/src/components/Breadcrumbs.jsx`

### 2. **История навигации**
- Отслеживание последних посещенных страниц
- Умный возврат назад с контекстом
- Интеграция с Command Palette
- Файл: `frontend/src/components/NavigationHistory.jsx`

### 3. **Улучшенный Command Palette**
- **Недавние страницы** — показываются первыми в списке
- **Умный поиск с синонимами** — находит по смыслу, не только по точному совпадению
  - "оплата" → находит "доход", "финансы", "деньги"
  - "урок" → находит "занятие", "lesson"
  - "задание" → находит "homework", "дз"
- **Расширенные ключевые слова** для быстрого доступа
- Файл: `frontend/src/components/CommandPalette.jsx`

### 4. **Сворачиваемые группы в сайдбаре**
- Группы "Работа", "Материалы", "Учёт" можно сворачивать/разворачивать
- Сохраняет состояние во время сессии
- Уменьшает визуальную перегрузку
- Обновлен: `frontend/src/Shell.jsx`

### 5. **Контекстные меню и быстрые действия**
- `ContextMenu` — контекстное меню с быстрыми действиями
- `QuickActions` — быстрые кнопки на карточках (ученики, уроки, задания)
- Поддержка горячих клавиш
- Файл: `frontend/src/components/ContextMenu.jsx`

### 6. **Плавающая кнопка действия (FAB)**
- Появляется только на мобильных устройствах
- Быстрый доступ к основным действиям
- Красивая анимация открытия/закрытия
- Файл: `frontend/src/components/FloatingActionButton.jsx`

### 7. **Улучшенные стили**
- Все новые компоненты стилизованы в соответствии с дизайн-системой
- Адаптивные стили для мобильных устройств
- Плавные анимации и transitions
- Обновлен: `frontend/src/styles.css`

## 🚀 Как использовать

### Breadcrumbs
```jsx
import { Breadcrumbs } from './components/Breadcrumbs';

// В компоненте страницы
<Breadcrumbs path={path} entities={{ 
  '123': 'Анна Смирнова' // ID → название для динамических сущностей
}} />
```

### История навигации
```jsx
import { useNavigationHistory } from './components/NavigationHistory';

function MyComponent() {
  const { recent, canGoBack, goBack } = useNavigationHistory();
  // recent — последние 7 уникальных страниц
  // canGoBack — можно ли вернуться назад
  // goBack() — вернуться на предыдущую страницу
}
```

### Quick Actions
```jsx
import { QuickActions } from './components/ContextMenu';

<QuickActions 
  compact={false}
  items={[
    { to: '/students/123', icon: 'user', label: 'Профиль' },
    { to: '/students/123/words', icon: 'cards', label: 'Словарь' },
    { onClick: handlePay, icon: 'wallet', label: 'Оплата' }
  ]} 
/>
```

### FAB (для мобильных)
```jsx
import { FloatingActionButton } from './components/FloatingActionButton';

<FloatingActionButton
  primaryAction={{ icon: 'plus', label: 'Создать', onClick: handleCreate }}
  actions={[
    { icon: 'calendar', label: 'Новое занятие', onClick: handleLesson },
    { icon: 'book', label: 'Новое задание', onClick: handleHomework }
  ]}
/>
```
