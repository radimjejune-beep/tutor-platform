# Платформа репетитора — бэкенд

Кабинеты репетитора, учеников и родителей: расписание, абонементы и оплаты, домашние задания, прогресс и ежемесячные отчёты.

Стек: Node.js + Express, PostgreSQL, JWT + bcrypt (как в CRM ДОД).

## Роли

| Роль | Что видит и делает |
|---|---|
| **Репетитор** | Всё: ученики, расписание, списания, оплаты, ДЗ, темы, отчёты, входы учеников и родителей |
| **Ученик** | Своё расписание, ДЗ (может сдавать ответы), прогресс, опубликованные отчёты, остаток абонемента и оплаты |
| **Родитель** | То же по каждому своему ребёнку, но только просмотр |

Вход — по логину и паролю. Email и телефоны не собираются: для ученика и родителя нужно только имя. Логин создаётся из имени (`Иван Петров` → `ivan.petrov`), пароль можно задать самому или сгенерировать.

Заметки репетитора (`notes` в карточке, `private_notes` в занятии) и черновики отчётов ученик и родитель не видят.

## Как работает списание

- Занятие списывается, когда статус меняется на **проведено**, **поздняя отмена** или **неявка**. Отмена вовремя не списывается.
- Списание идёт с самого старого активного абонемента, в котором остались занятия. Абонемент без остатка сам становится «завершён».
- Если абонемента нет, занятие списывается как разовое по своей цене.
- **Баланс** = все оплаты − стоимость абонементов − разовые занятия. Минус — долг, плюс — предоплата.
- Вернули статус обратно — списание отменяется автоматически.

## Запуск

1. Создать базу PostgreSQL и применить `migrations/001_init.sql` (через Adminer или `psql`). Проверка: 9 таблиц.
2. Скопировать `.env.example` в `.env` и заполнить (`DATABASE_URL`, `JWT_SECRET`, `FRONTEND_ORIGINS`).
3. Установить зависимости и создать свою учётку:
   ```bash
   npm install
   npm run create-tutor -- radim "Радим Кочка"
   ```
   Скрипт выведет временный пароль — после первого входа система попросит его сменить.
4. Запуск: `npm start` (порт из `PORT`, по умолчанию 3001). Проверка: `GET /api/health` → `{"ok":true}`.

## API (кратко)

Все запросы, кроме входа, — с заголовком `Authorization: Bearer <токен>`. Пока временный пароль не сменён, работают только `/api/auth/*`.

| Раздел | Запросы |
|---|---|
| Вход | `POST /api/auth/login`, `GET /api/auth/me`, `POST /api/auth/change-password` |
| Главная | `GET /api/dashboard` — для репетитора «сегодня» и «требует внимания», для ученика/родителя — сводка по каждому ребёнку |
| Ученики | `GET/POST /api/students`, `GET/PATCH /api/students/:id`, `POST /api/students/:id/login`, `POST /api/students/:id/parents`, `DELETE /api/students/:id/parents/:userId` |
| Входы | `POST /api/accounts/:userId/reset-password`, `PATCH /api/accounts/:userId` (блокировка) |
| Занятия | `GET /api/lessons?from=&to=&student_id=`, `POST /api/lessons` (с `repeat_weeks` для серии), `PATCH /api/lessons/:id`, `DELETE /api/lessons/:id` |
| Финансы | `GET /api/finance/students/:id`, `POST /api/finance/subscriptions`, `PATCH /api/finance/subscriptions/:id`, `POST/PATCH/DELETE /api/finance/payments`, `GET /api/finance/summary?month=2026-10` |
| ДЗ | `GET/POST /api/homework`, `PATCH/DELETE /api/homework/:id`, `POST /api/homework/:id/submit` (ученик) |
| Прогресс | `GET /api/progress/students/:id`, `POST /api/progress/topics`, `PATCH/DELETE /api/progress/topics/:id`, `GET /api/progress/students/:id/month-stats?month=`, `PUT /api/progress/reports`, `PATCH/GET /api/progress/reports/:id` |

## Персональные данные

Платформа хранит данные учеников, в том числе несовершеннолетних, — это обработка ПДн по 152-ФЗ. Перед запуском: получить письменное согласие (от родителя — за ребёнка) и отметить дату в карточке (`pd_consent_at`), разместить политику обработки ПДн, держать базу на российском хостинге.
