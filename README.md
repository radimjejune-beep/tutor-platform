# Платформа репетитора

Личные кабинеты для преподавателя, учеников и родителей: расписание, абонементы и оплаты, домашние задания, прогресс и ежемесячные отчёты.

- `backend/` — API (Node.js + Express + PostgreSQL). Подробности — в `backend/README.md`.
- `frontend/` — сайт (React + Vite), без UI-библиотек: своя дизайн-система в `src/styles.css`.

## Запуск на хостинге (как CRM ДОД на RelaxDev)

Два проекта из одного репозитория: бэкенд и фронтенд.

**1. База.** Создать базу PostgreSQL, открыть её в Adminer → «SQL-запрос» → по очереди выполнить файлы из `backend/migrations/` (`001_init.sql`, `002_assignments.sql`, `003_booking_legal.sql`, `004_room_library_telegram.sql`). Каждый файл применяется один раз.

**2. Бэкенд** (папка `backend`, команда запуска `npm start`). Переменные окружения:

| Переменная | Значение |
|---|---|
| `DATABASE_URL` | строка подключения к базе |
| `JWT_SECRET` | 64+ случайных символа (как сгенерировать — в `backend/.env.example`) |
| `FRONTEND_ORIGINS` | адрес сайта, например `https://tutor-cabinet.relaxdev.ru` |
| `APP_TIMEZONE` | `Europe/Moscow` |
| `TELEGRAM_BOT_TOKEN` | токен бота от @BotFather (необязательно — для итогов уроков в Telegram) |
| `TG_OPTION` | `1` — нужен на RelaxDev, чтобы сервер достучался до Telegram |

Проверка: `https://<адрес-бэкенда>/api/health` → `{"ok":true}`.

**3. Своя учётка.** В терминале бэкенда: `npm run create-tutor -- radim "Радим Кочка"` — выведет временный пароль.

**4. Фронтенд** (папка `frontend`, сборка `npm run build`, отдаётся папка `dist`). Переменная `VITE_API_URL` — адрес бэкенда без слэша в конце.

**5. Вход.** Открыть сайт, войти как `radim` с временным паролем, придумать свой.

## Как завести ученика

1. «Ученики» → «Ученик»: имя, кто (взрослый / подросток / ребёнок), цена, ссылка на доску в Холсте.
2. Вкладка «Доступ» → «Создать вход» (ученику) и/или «Родитель». Логин и пароль появятся один раз — кнопка «Скопировать для отправки» готовит текст для мессенджера.
3. Вкладка «Занятия» → «Занятие» → «Повторять 8 недель» — расписание на два месяца вперёд.
4. Вкладка «Оплаты» → «Абонемент», если ученик платит пакетом.

## Под себя

Название, подпись и ссылка для переноса занятий — в `frontend/src/config.js`. Цвета и шрифты — переменные в начале `frontend/src/styles.css`.
