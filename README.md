# Платформа репетитора

Личные кабинеты для преподавателя, учеников и родителей: расписание, абонементы и оплаты, домашние задания, прогресс и ежемесячные отчёты.

- `backend/` — API (Node.js + Express + PostgreSQL). Подробности — в `backend/README.md`.
- `frontend/` — сайт (React + Vite), без UI-библиотек: своя дизайн-система в `src/styles.css`.

## Запуск на хостинге (как CRM ДОД на RelaxDev)

Два проекта из одного репозитория: бэкенд и фронтенд.

**1. База.** Создать базу PostgreSQL, открыть её в Adminer → «SQL-запрос» → по очереди выполнить файлы из `backend/migrations/` (`001_init.sql`, `002_assignments.sql`, `003_booking_legal.sql`, `004_room_library_telegram.sql`, `005_games.sql`, `006_courses_vocab.sql`, `007_html_notifications.sql`, `008_tutors.sql`). Каждый файл применяется один раз.

**2. Бэкенд** (папка `backend`, команда запуска `npm start`). Переменные окружения:

| Переменная | Значение |
|---|---|
| `DATABASE_URL` | строка подключения к базе |
| `JWT_SECRET` | 64+ случайных символа (как сгенерировать — в `backend/.env.example`) |
| `FRONTEND_ORIGINS` | адрес сайта, например `https://tutor-cabinet.relaxdev.ru` |
| `APP_TIMEZONE` | `Europe/Moscow` |
| `TELEGRAM_BOT_TOKEN` | токен бота от @BotFather (необязательно — для итогов уроков в Telegram) |
| `TG_OPTION` | `1` — нужен на RelaxDev, чтобы сервер достучался до Telegram |

Проверка: `https://<адрес-бэкенда>/api/health` → `{"ok":true}`.

**3. Своя учётка.** В терминале бэкенда: `npm run create-tutor -- radim "Радим Кочка"` — выведет временный пароль.

**4. Фронтенд** (папка `frontend`, сборка `npm run build`, отдаётся папка `dist`). Переменная `VITE_API_URL` — адрес бэкенда без слэша в конце.

**5. Вход.** Открыть сайт, войти как `radim` с временным паролем, придумать свой.

## Как завести ученика

1. «Ученики» → «Ученик»: имя, кто (взрослый / подросток / ребёнок), цена, ссылка на доску в Холсте.
2. Вкладка «Доступ» → «Создать вход» (ученику) и/или «Родитель». Логин и пароль появятся один раз — кнопка «Скопировать для отправки» готовит текст для мессенджера.
3. Вкладка «Занятия» → «Занятие» → «Повторять 8 недель» — расписание на два месяца вперёд.
4. Вкладка «Оплаты» → «Абонемент», если ученик платит пакетом.

## Курс по учебнику и словарь

1. «Курсы» → «Импорт» → файл курса (например, `solutions-elementary-1F.json`). Появятся упражнения в библиотеке и курс с юнитами.
2. Карточка ученика → вкладка «Курс» → выбрать учебник и юнит. Слова юнита сами попадут в словарь ученика.
3. Перед уроком всё видно на главной в блоке «Сегодня»: юнит, прошлый урок, ДЗ, словарь, оплата.
4. В комнате урока «Материалы юнита» добавляет упражнения, «Завершить урок» отмечает занятие, выдаёт ДЗ и переводит на следующий юнит.
5. Ошибки в упражнениях попадают в словарь ученика. Ученик повторяет слова во вкладке «Словарь»: интервалы 1, 3, 7, 14, 30 дней.

## Несколько репетиторов

- Первый репетитор (тот, кто создан командой `create-tutor` или был в базе до `008_tutors.sql`) — сисадмин. У него в меню есть раздел «Учителя».
- В «Учителях» сисадмин создаёт репетиторам входы, сбрасывает пароли, отключает учётки и открывает или закрывает регистрацию.
- Пока регистрация открыта, на странице входа есть ссылка «Создать свой кабинет бесплатно».
- У каждого репетитора свои ученики, группы, библиотека, курсы, задания, настройки записи и документы. Чужие данные не видны никому, включая сисадмина.
- Документы конкретного репетитора открываются по ссылке `#/legal/offer?t=логин`.

## HTML-уроки

Готовый интерактивный урок (.html) загружается в «Библиотека» → «Уроки». Его можно добавить в урок или выдать как ДЗ. Чтобы результат ученика сохранился, урок вызывает:

```js
if (window.Lessonfold) window.Lessonfold.report({ correct: 8, total: 10, details: [{ ok: false, prompt: '…', expected: '…', word: { term: 'keen on', translation: 'увлекаться' } }] });
```

Слова из `details` с ошибкой (`ok: false` и `word`) попадают в словарь ученика.

## Мотивация, заявки, цены, каталог (миграция 009_growth.sql)

- Ученик получает очки за повторение слов, упражнения и сданное ДЗ. На главной видны серия дней подряд и лига недели среди учеников одного репетитора (выключается в Настройки → Страница записи).
- За час до урока ученику открывается разминка на 8 слов с ошибками. Результат виден репетитору в карточке урока на экране «Сегодня».
- Страница записи: `#/join/<логин>`. Тест уровня A1–B2 и заявка. Заявки: Ученики → Заявки, одной кнопкой превращаются в ученика.
- Доход → Цена: реальный заработок в час с каждого ученика и готовое сообщение о новой цене.
- Каталог: репетиторы делятся HTML-уроками и упражнениями. Кнопка «В каталог» в карточке материала.

## Удобство на уроке

- Звёздочка у задачи добавляет её в «Избранное». Фильтр «Избранное» есть в библиотеке и в выборе задач для урока и ДЗ.
- Комментарий к задаче (например, «для 13 задания ОГЭ») видит только репетитор, в том числе при выборе задач на уроке.
- В «Завершить урок» есть блок «Родителям»: итоги в Telegram через бота или готовый текст для WhatsApp, MAX и любого чата.
- В списке расписания у каждого урока кнопки звонка и комнаты урока. Ссылка на доску Miro сама превращается во встраиваемую.

## Под себя

Название, подпись и ссылка для переноса занятий — в `frontend/src/config.js`. Цвета и шрифты — переменные в начале `frontend/src/styles.css`.
